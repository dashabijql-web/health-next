# 目标气质
3D 线框人体铺满整个内容区当背景。身份、当前体征、近几小时走势、联系此人，全部做成半透明玻璃条贴在四周。透过玻璃能看到后面的人体、扫描线和粒子。不要再左右两栏把人体关在中间一个盒子里。

# 新页面
1. 新路由，例如 /health-monitor/body-360-immersive，侧栏加一项「沉浸人体」，和「360° 人体」并存。
2. 布局尽量吃满 Layout 内容区（现有 fill 模式）。不要在人体外再套一层实心大卡片。
3. 玻璃层建议：
   - 上：人员切换 + 演示标记 + 采集时间/新鲜度
   - 左：身份（姓名工号班组）+ 手表遥测，底部钉「发消息 / 语音提醒 / 打电话·未配置」
   - 人体周围或玻璃角：心率、血氧、收缩压/舒张压、体温、压力（有数显示数，没有 --）
   - 下：近 1h / 3h / 6h 走势小曲线通栏，高度大约 120～150px，半透明，能隐约看到人体下半身
4. 玻璃样式：backdrop-filter 模糊 8～12px，背景 rgba(8,12,18,0.45～0.62)，边框 1px rgba(255,255,255,0.10)，圆角 6～8px。必须保证字可读：深色底 + 足够对比，不要纯透明到看不清数字。
5. 3D 必须仍可拖拽旋转、自动旋转、减少动态、重置视角。控制条也做成玻璃，贴底或贴走势上方，不要挡住曲线。
