# 页面结构（必须按这个摆）
1. 顶栏
   - 标题：值班名单
   - 一句说明：最近 15 分钟有上报视为在线；5 分钟内视为新鲜
   - 刷新时间、手动刷新按钮（演示里点刷新只更新「刷新时间」即可）

2. 四个数字胶囊（不要用当前页表格行数冒充总数）
   - 在线、当前异常、数据陈旧、无有效体征
   - 演示数据里写死一组和名单对得上的数字，例如在线 186、异常 12、陈旧 9、无数据 7

3. 筛选一行
   - 搜索：姓名或工号
   - 状态：全部 / 异常 / 正常 / 陈旧 / 无数据
   - 班组：下拉，选项从演示人员的班组去重（采掘一队、综采二队等），不要做部门管理
   - 重置

4. 表格（主内容，桌面不要改成大卡片矩阵）
   列：姓名、工号、班组、心率、血氧、血压、体温、压力、状态、采集时间、操作
   - 没数的格子显示 --
   - 状态四种：正常 / 异常 / 陈旧 / 无数据，用克制色点或色条，不要整行霓虹
   - 异常行左侧一条细色条
   - 操作：查看人体；有手表的显示发消息/语音（点了只提示「演示：未真正下发」）；没手表的按钮禁用
   - 点姓名 = 查看人体

5. 底部分页
   - 每页 20 条（演示名单请准备至少 80～120 人，才能看出分页）
   - 显示 第 x / y 页，共 n 条
   - 筛选后分页按筛选结果算

6. 空态
   - 筛完没人：无符合条件的人员
   - 不要空白一片

# 演示数据字段（以后我按这些接真接口，不要乱起名）
每人一条：
- empCode 工号
- empName 姓名
- team 班组（字符串）
- jobName 工种（表上可以不显示，但数据里留着）
- imei 手表号，没有则 null
- heartRate, bloodOxygen, systolic, diastolic, temperature, pressure  没有则 null
- status: normal | warning | stale | no_data
- collectedAt 采集时间字符串，无数据可空
点「查看人体」跳到：
